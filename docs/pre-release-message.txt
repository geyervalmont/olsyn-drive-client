Here is the Olsyn Drive test version for Windows: <download link to olsyn-drive.exe> and its install wizard: <download link to install.ps1>
It is an unsigned pre-release, so Windows Security has to be told about its program folder, once, by you. The wizard shows you how, checks it, then installs:
1. Save both files in your Downloads folder.
2. Start menu > type PowerShell > right-click Windows PowerShell > Run as administrator > Yes.
3. Paste this line and press Enter, then follow the steps on screen:
   & ([scriptblock]::Create((Get-Content -Raw "$HOME\Downloads\install.ps1"))) -PreRelease -Installer "$HOME\Downloads\olsyn-drive.exe"
The wizard never changes Windows Security itself; you make the one change it points you to.
(Once releases are on the drive this becomes one line: irm https://drive.olsyn.com/install.ps1 | iex)

By hand instead: Windows Security > Virus & threat protection > Manage settings > Exclusions > Add or remove exclusions > Add an exclusion > Folder > %LOCALAPPDATA%\Programs\Olsyn Drive (create the folder if it is not there). Only that folder: never the cache, W:, Downloads or a whole disk. Then open olsyn-drive.exe; on "Windows protected your PC" choose More info, then Run anyway.
If it was removed anyway, your files waiting to upload are safe: Windows Security > Protection history > the Olsyn Drive item > Actions > Restore, or add the exclusion, download again and install; they carry on.
Full steps, and how to remove the exclusion later (the signed release won't need it): https://github.com/geyervalmont/olsyn-drive-client/blob/main/docs/pre-release-windows.md
