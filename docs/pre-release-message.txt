Olsyn Drive for Windows, test version (unsigned pre-release): <download link>

Do step 1 BEFORE downloading, or Windows Security will delete it (it did in our tests; it is a false alarm on unsigned software).

1. Make the folder and tell Windows Security about it:
   - Press Win+R, paste  %LOCALAPPDATA%\Programs  and press Enter. Create a new folder there named exactly:  Olsyn Drive
   - Open Windows Security > Virus & threat protection > Manage settings > Exclusions > Add or remove exclusions > Add an exclusion > Folder, and pick that "Olsyn Drive" folder. Only this folder, nothing else.
2. Download OlsynDrive.exe and save it INTO that "Olsyn Drive" folder (not Downloads). Keep its name.
3. Double-click it there. If "Windows protected your PC" appears: More info > Run anyway. Click OK to install, then Sign in and approve in your browser. It asks once for administrator approval to install the WinFsp driver. Your drive appears as W:.

If Windows Security removes it anyway: nothing is lost, files waiting to upload stay safe. Check the exclusion from step 1, then Windows Security > Protection history > the item > Actions > Restore (or download again into the folder) and run it again.

Full steps and how to remove the exclusion later (the signed release will not need it):
