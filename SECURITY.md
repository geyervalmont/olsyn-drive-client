# Security

Please do not report security problems in public issues or pull requests.

Report a vulnerability privately to **security@example.invalid** (placeholder: replace with the project's
security contact before relying on it), or through GitHub's private vulnerability reporting on this repository
when it is enabled. Include what is affected (version from `olsyn-drive version`, Windows version), how to
reproduce it, and what an attacker could do with it. Do not include real tokens, credentials or customer files.

You will get an acknowledgement within a few working days. Fixes are released as client updates (signed release
manifests, see [docs/design.md](docs/design.md)); please allow time for a fix before disclosing.

## Scope

The desktop client in this repository: the agent, the mount, the desktop app, the installer and the updater.
The drive service itself is out of scope here.
